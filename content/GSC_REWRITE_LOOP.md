# GSC rewrite loop (biweekly)

Connect Google Search Console for `perlemamalactation.co.za` first — see [SEO.md](../SEO.md).

## Every two weeks

1. Open GSC → Performance → last 28 days.
2. Export or scan **Queries** and **Pages**.
3. Flag pages where:
   - Average position **8–20** and impressions ≥ 10 (striking distance)
   - High impressions + low CTR (title/meta problem)
   - Impressions falling week over week (decay)
4. Prefer rewriting those URLs before writing brand-new topics.
5. After rewrite: bump copy in `src/data/pages.js`, rebuild, request indexing.

## Rewrite checklist

- [ ] Title leads with the query’s intent
- [ ] Meta description invites a click without clickbait
- [ ] Opening answers the query in two sentences
- [ ] H2s / FAQ cover long-tail questions now showing in GSC
- [ ] Internal links to services + WhatsApp CTA still valid
- [ ] EN↔AF pair stays in sync when intent is shared
- [ ] Credentials remain accurate (LC CBI — not IBCLC)

## Cadence vs new content

| Priority | Work |
| --- | --- |
| P0 | Striking-distance rewrites |
| P1 | CTR underperformers |
| P2 | Missing FAQ answers on existing problem pages |
| P3 | New extra topics (reflux, DMER, weaning) only after Tier A is healthy |
