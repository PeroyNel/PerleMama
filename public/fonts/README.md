# Fonts Directory

## Tan Pearl Font

1. Download Tan Pearl from: https://dafont.style/download/tan-pearl-font.html
2. Extract the ZIP file
3. Copy the font file(s) (usually `.ttf` or `.otf` format) to this directory
4. Rename the file to `TanPearl.ttf` (or keep the original name and update the path in `src/index.css`)

The font will automatically be loaded once the file is placed here.

## Moontime Font

When you have the Moontime font files, add them here and uncomment the `@font-face` declaration in `src/index.css`.
